# Academic Research & Writing Skills Set

Ten discipline-neutral skills for an academic research agent. The set supports the arc from a broad question through source research, literature review, argument development, revision, citation verification, publication planning, and public communication.

The skills are designed for faculty, students, librarians, and other researchers. They preserve human authorship and judgment, require transparent source use, and avoid treating AI output as evidence.

## Included skills

1. **Research Support Guide** — routes a request to the smallest useful workflow.
2. **Research Project Planner** — turns a broad idea into a feasible, bounded project.
3. **Literature Review Helper** — plans, documents, and synthesizes narrative or formal evidence reviews.
4. **Academic Source Searcher** — finds, evaluates, verifies, and logs sources across disciplines.
5. **Argument Builder** — maps claims, evidence, warrants, alternatives, and counterarguments.
6. **Draft Revision Coach** — diagnoses structure and produces a prioritized revision plan.
7. **APA 7 Citation Checker** — verifies source identity, claim support, quotations, scholarly-record status, and APA 7 form.
8. **Scholarly Writing Editor** — improves prose while preserving meaning and disciplinary voice.
9. **Publication Planner** — compares credible venues and prepares a transparent submission plan.
10. **Public Writing Adapter** — translates completed research without flattening evidence or uncertainty.

## Install

The downloadable set contains ten individual skill ZIP files.

1. Unzip the outer set once.
2. Do not unzip the ten individual skill ZIP files.
3. Upload each individual ZIP through the skill-installation interface in a platform that supports packaged skills.
4. Install all ten for a general academic research agent, or install only the skills relevant to the intended work.
5. Paste `AGENT-INSTRUCTIONS.md` into the Agent's instruction field.

Product interfaces and feature availability change. Follow the platform's current skill-installation guidance if the labels differ.

## Recommended first test

> I am interested in how generative AI feedback affects undergraduate writing, but I am not sure whether I need a literature review, a small empirical study, or both. Help me turn this into a defensible research project and show me what sources I should examine first.

This prompt tests routing, clarification, project planning, source strategy, and human-review checkpoints without telling the Agent which skills to choose.

## Research and citation defaults

- Source authority is contextual and discipline-dependent.
- The Agent should prefer original sources and explain what it could and could not access.
- “Discovered,” “retrieved,” “reviewed,” and “verified” are distinct source states.
- APA 7 is the default citation style, but a course, discipline, or venue's required style controls.
- A literature review is not called systematic or scoping unless its method supports that label.
- Significant claims should be connected to sources in a traceability table or evidence ledger.

## Important limits

These skills do not replace a subject librarian, methodologist, statistician, archivist, community partner, research-ethics office, data steward, editor, or the researcher's judgment. They do not grant access, permissions, ethics approval, or authority to submit or communicate externally.
